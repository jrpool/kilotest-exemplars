# kilotest-exemplars

Frame-source documents for the defect-exemplar pages of [Kilotest](https://github.com/jrpool/kilotest), served by GitHub Pages so that kilotest.com pages can embed them in cross-site iframes.

Each file here is an identical copy of a document in the `exemplars/` directory of the kilotest repository and must be kept in sync with it; the copy is what makes the frame cross-site rather than same-origin. `iframes-frame.html` is the frame source of the [iframes exemplar](https://kilotest.com/exemplars/iframes.html). See `docs/decisions/013-exemplar-pages.md` in the kilotest repository for the design.
